State Management

Overview

The app uses Zustand v5 for global state. Each store is a standalone module in store/. Zustand was chosen over Redux for its minimal boilerplate and hook-first API.

Persistence: themeStore and languageStore use Zustand's persist middleware with AsyncStorage. Auth tokens are stored separately in SecureStore.

authStore — store/authStore.ts

Manages authentication lifecycle: login, signup, Google auth, session restoration, and logout.

State
Field Type Default Description
user User | null null Current user object from /me
isAuthenticated boolean false True after successful login/signup
isLoading boolean false True during async operations
isRestoringSession boolean true True until restoreSession completes on app launch
Actions
Method Params Returns Description
login email, password AuthResponse Calls /login, stores tokens, sets user
signup SignupRequest AuthResponse Calls /signup, stores tokens, sets user
googleAuth — AuthResponse Google Sign-In → /auth/google → stores tokens
logout — void Fire-and-forget /logout, clears tokens + state
restoreSession — void On launch: checks stored access token → calls /me → restores state or clears
setUser User void Direct user setter (for profile updates)

themeStore — store/themeStore.ts

Persists user's theme preference. The useTheme() hook reads this store and computes isDark using the system color scheme.

Field / Action Type Description
mode "light" | "dark" | "system" User preference (default: "system")
setMode(mode) Function Set explicit mode
toggleMode() Function Cycle: light → dark → system
Important: The store does NOT export isDark directly. The useTheme() hook computes it: isDark = mode === "dark" ? true : mode === "light" ? false : systemColorScheme === "dark".

languageStore — store/languageStore.ts

Persists selected language and provides it to the i18n system on app launch.

Field / Action Type Description
language string Language code: "en" | "ar" | "ur" | "fr" | "de" | "tr"
setLanguage(lang) Function Change language, updates i18n and persists to AsyncStorage

profileSetupStore — store/profileSetupStore.ts

Manages the 9-step profile wizard: accumulated profile data, masterdata cache, and step detection.

State
Field Type Description
gender string Selected gender (used for gender-specific options)
profileData Record<string, any> Accumulated fields from all completed steps
masterdata Record<string, MasterdataItem[]> Cached masterdata (height, complexion, etc.)
Step Detection — getIncompleteStep(profile)

Returns the first incomplete step number (1–9), or 0 if all fields are filled:

if (!profile.profileName) → return 1 // Basics if (!profile.mother_tongue) → return 2 // Language if (!profile.marital_status) → return 3 // Marital if (!profile.height) → return 4 // Physical if (!profile.education) → return 5 // Education if (!profile.sect) → return 6 // Religion if (!profile.smoking) → return 7 // Lifestyle if (!profile.current_location.city)→ return 8 // Location if (!profile.profile_manager) → return 9 // Manager return 0 // All complete → go to main app

Custom Hooks — hooks/

Hook File Returns Description
useTheme() useTheme.ts { theme, isDark, toggleTheme, setTheme } Computes isDark from mode + system color scheme
useLanguage() useLanguage.ts { t, isRTL, language, changeLanguage } i18next translation function + RTL flag
useAuth() useAuth.ts { user, isAuthenticated, ... } Convenience wrapper for authStore
useFirstLaunch() useFirstLaunch.ts { isFirstLaunch } AsyncStorage flag for onboarding
useResponsive() useResponsive.ts scale(size) Scale sizes based on screen width
useToast() useToast.tsx { show(type, msg) } Toast notification system

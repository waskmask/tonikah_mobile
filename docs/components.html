UI Components

15 reusable components in components/ui/. All support dark mode (via useTheme()) and RTL (via useLanguage()).

Input — Input.tsx

Full-width text input with left/right icon slots, dark mode support, RTL-aware layout, focus state ring, and error display.

Prop Type Default Description
label string — Optional label above the input
error string — Error message (red border + text below)
leftIcon ReactNode — Icon on the left (right in RTL)
rightIcon ReactNode — Icon on the right (left in RTL)
containerStyle string "" Extra NativeWind classes on wrapper
…plus all TextInputProps from React Native
Dark Mode Colors
   Background #1E293B    Text #E2E8F0    Placeholder #64748B    Border #334155    Focus #FE8A7B

FormField — FormField.tsx

Exports three sub-components used across all profile setup steps:

Export Props Description
FieldLabel text: string, required?: boolean Label with optional red * asterisk. RTL-aware row direction.
ErrorText text: string Red error message below field. RTL text-align.
SelectField value, placeholder, onPress, icon, hasError? Pressable that looks like a text input with value/placeholder + icon. Full-width, dark mode bg/border, RTL row-reverse.

GradientButton — GradientButton.tsx

Primary CTA button with a coral-to-pink gradient (#FE8A7B → #F34B6F). Supports loading spinner, disabled state, and outline variant.

Prop Type Description
title string Button label text
onPress () => void Press handler
loading boolean Shows ActivityIndicator, hides title
disabled boolean 50% opacity + press disabled
variant "solid" | "outline" Solid gradient or bordered outline (auto full-width)
widthMode "auto" | "full" Controls button width

SingleSelectSheet — SingleSelectSheet.tsx

Bottom sheet modal for selecting a single option. Animated slide-up with handle bar, search, and gradient checkmark.

Prop Type Description
visible boolean Controls visibility
onClose () => void Dismiss handler
onSelect (value: string) => void Called on option tap, auto-closes
options SelectOption[] { value, label, description? }
selected string Currently selected value
title string Sheet header title
searchEnabled boolean Shows search bar
minHeight number Minimum sheet height (default: 40% screen)

MultiSelectSheet — MultiSelectSheet.tsx

Like SingleSelectSheet but allows multiple selections with a Confirm button. Supports maxSelections limit.

Prop Type Description
onConfirm (values: string[]) => void Called on Confirm tap with all selected values
selected string[] Currently selected values array
maxSelections number Max items allowed (e.g. 2 for nationality)
searchEnabled boolean Shows search bar

Text — Text.tsx

Custom Text component with variant system for consistent typography. Supports RTL text alignment.

Variant Font Size Use
h1 Manrope 700 28 Page headlines
h2 Manrope 700 24 Section headings
heading Manrope 700 22 Sub-headings
heading-sm Manrope 600 18 Card titles, sheet headers
body Inter 400 15 Default body text
body-sm Inter 400 13 Labels, helper text
caption Inter 400 11 Error text, timestamps

Checkbox — Checkbox.tsx

Animated checkbox with gradient fill when checked. Props: checked: boolean, onToggle: () => void, label?: string, error?: string.

Button — Button.tsx

Basic button with variants: primary, secondary, outline, ghost. Props: title, onPress, variant, size, disabled.

Badge — Badge.tsx

Colored badge pill. Props: text: string, variant: "success" | "warning" | "error" | "info".

Card — Card.tsx

Rounded card container with dark mode border/background. Props: children, style?.

Modal — Modal.tsx

Centered modal overlay. Props: visible: boolean, onClose: () => void, children.

Toast — Toast.tsx

Animated top-slide notification. Types: success, error, info, warning. Auto-dismisses after 3 seconds. Managed via useToast() hook.

ProgressBar — ProgressBar.tsx

9-segment progress indicator for profile setup. Props: currentStep: number (1–9). Highlights completed steps with gradient.

PaginationDots — PaginationDots.tsx

Horizontal dot indicators for onboarding carousel. Props: count: number, activeIndex: number.

LanguagePicker — LanguagePicker.tsx

Bottom sheet language selector with 6 languages (English, Arabic, Urdu, French, German, Turkish). Updates i18n locale, persists to languageStore, and triggers app re-render. Shown in auth header.

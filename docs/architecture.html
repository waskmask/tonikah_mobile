Architecture Overview

Overview

toNikah is built with Expo (SDK 54) using the managed workflow. The app uses Expo Router v6 for file-based navigation, Zustand for state management, and a custom fetch-based HTTP client with JWT token refresh. The architecture is organised around route groups that map to logical feature boundaries.

Key Principle: Every screen lives inside the app/ directory as a file route. Shared business logic lives in lib/, reusable UI in components/ui/, and global state in store/.

Routing & Navigation

The app uses Expo Router v6 with file-based routing. The root _layout.tsx sets up a Stack navigator with four route groups:

Route Group Navigator Header Screens
(onboarding) Stack Hidden 3-screen carousel
(auth) Stack Hidden login, signup, verify-email
(profile-setup) Stack Hidden step1 through step9
(tabs) Bottom Tab Visible home, likes, messages, profile

Route Groups Detail

  • login.tsx — Email/password form + Google Sign-In button. Uses react-hook-form with mode onChange. On success → navigates to / (index.tsx decision tree).
  • signup.tsx — Email/password/confirm + Terms checkbox + Google. On email signup → redirects to verify-email. On Google → auto-verified, goes to /.
  • verify-email.tsx — Shows "check your inbox" with resend button. Receives email param.

A linear 9-screen wizard driven by profileSetupStore.getIncompleteStep(). Each step uses shared components:

  • FieldLabel, ErrorText, SelectField from FormField.tsx
  • SingleSelectSheet / MultiSelectSheet bottom sheets with search
  • ProgressBar showing current step (1–9)
  • GradientButton for the Continue/Finish action

See Profile Setup for step-by-step payloads and validation.

Bottom tab navigator with 4 screens: Home (Explore), Likes, Messages, Profile. Requires completed profile. Users are only redirected here after all 9 steps pass.

Entry Point Decision Tree

The root index.tsx runs on every app launch / navigation to /. It determines where the user should land:

index.tsx Decision Tree: ┌─────────────────────────────────────────────────┐ │ isRestoringSession? ──yes──▶ Loading spinner │ │ │ no │ │ isFirstLaunch? ──yes──▶ /(onboarding) │ │ │ no │ │ isAuthenticated? ──no──▶ /(auth)/login │ │ │ yes │ │ email_verified === false? ──yes──▶ verify-email │ │ │ no │ │ getIncompleteStep(profile) > 0? │ │ │ yes ──▶ /(profile-setup)/step{N} │ │ │ no ──▶ /(tabs)/home │ └─────────────────────────────────────────────────┘
